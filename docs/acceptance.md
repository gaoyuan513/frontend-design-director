# Form Studies 验收记录

## v1 → v2

| v1 | v2 |
| --- | --- |
| 静态首屏与六图轮播 | 透视投影线束，指针、拖拽和滚动分别控制视角与线束间距 |
| 固定双栏展示 | 开场、实验目录、交互详情和项目收尾 |
| 展示图说明六种方向 | 六个独立可操作实验，支持详情深链 |
| 注重通用布局和功能回归 | 创意概念比较、动效编排、设备替代路径与 Creative Quality Gate |

新版以形态仪为主要创意概念。使用原生 JavaScript 和 Canvas 2D 将空间曲线投影到页面。画布视口外不安排新帧，像素倍率有上限。排班与运行日志为本地演示数据，实验状态在关闭后重置。

## 浏览器与录屏

Edge 157.0.4341.60，Windows。本地桌面视口 1360 × 820，移动端为 390 × 844 触控模拟。

| 范围 | 已验证 |
| --- | --- |
| 首屏 | 指针移动和拖拽均改变画布输出；正向滚动拉开线束，反向滚动收回 |
| 实验入口 | 横拖改变位置而不误开详情，键盘可打开全部六个实验，Escape 关闭并恢复到触发元素 |
| 六个实验 | 调节折叠幅度、切换编辑章节、选择班次并发布、重试失败任务、拖动画布并选中标本、重排场次 |
| 触控与减弱动态 | 点按旋转、横滑后点按详情、发布并用浏览器返回，刷新深链后可关闭 |
| 资源与控制台 | 上述检查无控制台错误或 HTTP 失败 |

首轮检查发现标题在 390px 视口被裁切、手势结束后轻触偶发遗漏。调整手机字号并修正触控事件交接后复测通过。此次也为原生对话框补上可访问名称和初始焦点，为实时切换系统减弱动态设置补上画布刷新。

本机单标签页连续触发旋转时，120 次帧间隔中位约 10.1ms，P95 约 15.1ms。冷启动主文档与首批三个脚本及样式资源合计约 24.7kB。该采样未覆盖真实手机、Safari 或低端设备。

桌面视频 1280 × 720，约 25 秒，包含首屏、拖拽、滚动和六种实验。手机视频 420 × 840，约 9 秒，演示触控流程。视频来自 Edge 的实际浏览器帧，加入了章节字幕，经过节奏调整，无音轨。手机素材取自触控模拟。
