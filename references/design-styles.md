# Select by the visitor’s main action

|Primary direction|Choose when|Composition and acceptance test|
|---|---|---|
|Creative / Experimental|Explore a campaign or studio identity|One expressive scene with stable navigation. A visitor can reach work and contact before effects load.|
|Premium / Editorial|Read a story or evaluate a luxury offering|Sequence image, caption and readable column. Scale display type by viewport. Check long titles and line length.|
|SaaS / Product|Understand value and start using a service|Put a real workflow beside the promise. Trace from feature explanation through signup or next action.|
|Dashboard / Workspace|Monitor, compare and operate on persistent data|Use list, inspector and activity where simultaneous context helps. Preserve selection through refresh. Collapse to drill-down on mobile.|
|Spatial Gallery|Browse a collection by position or proximity|Pair a pannable plane with a searchable list and deep-linked detail. Restore position on return.|
|Minimal / Swiss|Scan an index, schedule or structured collection|Align metadata on a shared grid. Use type weight, rules and rhythm to distinguish levels. Check ordering at one column.|

If a gallery is explicitly requested, test whether spatial relationships help discovery. Keep checkout and account flows conventional. For an AI product distinguish the public acquisition page from the signed-in run console before selecting a mode.
