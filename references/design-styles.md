# Select by the visitor’s main action

Use these directions when the brief leaves visual choices open. Start with the content a visitor needs and the action they should be able to complete. The same direction can support different compositions as content density and available assets change.

|Primary direction|Choose when|Composition and acceptance test|
|---|---|---|
|Creative / Experimental|Explore a campaign or studio identity|One expressive scene with stable navigation. A visitor can reach work and contact before effects load.|
|Premium / Editorial|Read a story or evaluate a luxury offering|Sequence image, caption and readable column. Scale display type by viewport. Check long titles and line length.|
|SaaS / Product|Understand value and start using a service|Put a real workflow beside the promise. Trace from feature explanation through signup or next action.|
|Dashboard / Workspace|Monitor, compare and operate on persistent data|Use list, inspector and activity where simultaneous context helps. Preserve selection through refresh. Collapse to drill-down on mobile.|
|Spatial Gallery|Browse a collection by position or proximity|Pair a pannable plane with a searchable list and deep-linked detail. Restore position on return.|
|Minimal / Swiss|Scan an index, schedule or structured collection|Align metadata on a shared grid. Use type weight, rules and rhythm to distinguish levels. Check ordering at one column.|

If a gallery is explicitly requested, test whether spatial relationships help discovery. Keep checkout and account flows conventional. For an AI product, identify whether the request concerns the public acquisition page or the signed-in run console before selecting a mode.

For a new marketing page, use one coherent visual hierarchy across the opening, supporting evidence and call to action. Give imagery a concrete subject and a layout role. Stack or crop deliberately at narrow widths. Check that the main proposition and next action remain clear with realistic copy and before optional media load.

## Plan open visual decisions

For a new page or substantial redesign with open visual choices, sketch a short plan before building. Reuse the project's existing design brief and tokens where they apply.

| Decision | Worked example for a workshop schedule |
| --- | --- |
| Audience, task, and real content | A first-time visitor needs to find an available evening workshop and open its booking page. Lead with the published sessions, including date, location, and availability. |
| Composition and visual rules | Use the existing heading scale, align times for scanning, and reserve the action accent for booking. Group sessions by day on narrow screens. Use motion to clarify changes when filtering. |
| Acceptance and likely failure | Use a long session title and a sold-out session in a narrow browser viewport. Date, location, and availability remain readable without horizontal page scroll, and the available session still opens booking. |

After rendering, ask how the strongest visual element helps this audience complete the intended task. Revise any choice that had a clear purpose in the plan but obscures the task in the real page.
