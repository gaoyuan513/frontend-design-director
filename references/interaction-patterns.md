# Interactions that communicate state

- **Streaming logs** — Follow new entries while the user is at the end. Preserve reading position after they scroll up and offer a way to jump to the latest entry. Derive the run status from actual events. See [product workflows](product-interfaces.md) for reconnect, cancellation and retry.
- **Gallery** — Start with semantic links. Use a movement threshold to distinguish click from drag and bound any inertia. A horizontal strip can reserve horizontal gestures while letting the browser handle vertical scrolling. Clear drag state on release, cancellation or lost capture. Limit click suppression to the completed gesture so the next deliberate tap still opens its target. Provide keyboard and list access to the same destinations.
- **Creative transitions** — Animate the element whose state changes and preserve history across scenes. Coordinate the visual transition with focus and interaction so hidden or departing content cannot capture input. When motion is reduced, enter the resolved state directly and keep the navigation and content available.
- **3D** — Keep an HTML index or poster with real links available before the optional scene loads. Use the same path if rendering or asset loading fails. Pause expensive rendering when the scene is hidden. Dispose of listeners, textures and animation frames on navigation.
