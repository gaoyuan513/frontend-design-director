# Frontend Design Director

1. **Read the project.** Trace the primary task through actual routes, content, data, permissions and recovery states. Inspect the stack and design primitives. Capture a runnable baseline when possible.
2. **Choose a concept before markup.** Compare three distinct concepts internally. Give each a metaphor, focal object, composition, input, visible state change and feasible renderer. Select against the user’s intent and devices using [design modes](references/design-styles.md). For an explicitly experimental brief, prototype the strongest idea before reducing scope.
3. **Direct the image and the motion.** Define type scale, material, depth, composition and a recurring visual motif. For experimental work use the [creative playbook](references/creative-direction.md) and sample one or two [case studies](references/award-winning-case-studies.md). For other projects choose a relevant [source category](references/design-sources.md). Translate a principle into original work and label which behavior you actually observed.
4. **Build the defining input first.** On a creative page, deliver a signature interaction, a narrative scene change and a deeper content action. Verify their prototype in the browser before polishing secondary sections. Keep a touch, keyboard and reduced-motion path to the same outcome. For product work, preserve existing contracts and complete the relevant loading, empty, failure and success states.
5. **Implement in the appropriate stack.** Reuse existing primitives. Add a rendering library when it creates a visible capability the concept needs. Adapt the [token example](assets/design-tokens.example.json) when starting a new theme. Use [interaction patterns](references/interaction-patterns.md) for focused guidance.
6. **Test before calling it finished.** Run project checks and [browser QA](references/quality-checklist.md). For creative work, apply the gate on desktop and narrow screens, measure active input and retest failures. Capture a real recording when requested. Report the implemented behavior, evidence and remaining limits.
